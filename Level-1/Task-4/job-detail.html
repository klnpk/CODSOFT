Frontend Developer

Company: Tech Solutions Pvt Ltd

Location: Hyderabad, India

Experience: Fresher / 0-1 Years

Salary: ₹4 - ₹6 LPA

Job Type: Full-Time

📋 Job Description

We are looking for a passionate and motivated Frontend Developer to join our growing development team. The candidate should have a good understanding of HTML, CSS, JavaScript, and modern web development concepts. Freshers with strong problem-solving skills and a willingness to learn are encouraged to apply.

🛠️ Required Skills

  • HTML5 & CSS3
  • JavaScript (ES6 Basics)
  • Responsive Web Design
  • Basic knowledge of React (Preferred)
  • Git & GitHub Fundamentals

🎯 Key Responsibilities

  • Develop and maintain responsive web pages.
  • Collaborate with UI/UX designers and backend developers.
  • Write clean and maintainable code.
  • Test and debug web applications.
  • Participate in team discussions and code reviews.

🎓 Qualifications

  • B.Tech / B.E / MCA / BCA or related degree.
  • Good understanding of frontend technologies.
  • Strong communication and teamwork skills.
  • Eagerness to learn and adapt to new technologies.

🎁 Benefits

  • Competitive salary package.
  • Flexible working environment.
  • Learning and career growth opportunities.
  • Friendly and collaborative team culture.
